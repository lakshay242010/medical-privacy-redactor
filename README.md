# BioRedact 🏥

BioRedact is a privacy-preserving medical text redactor built with Python and Streamlit. It automatically detects and masks sensitive patient information (PII/PHI) such as names, dates, phone numbers, and addresses from clinical notes.

## 🚀 Features
- **PII/PHI Redaction:** Masks personal patient details automatically using regular expressions.
- **Side-by-Side View:** Clear comparison of raw medical notes vs. redacted secure output.
- **Clinical Disclaimer:** Built-in notice for safe healthcare data handling.

## 🛠️ Tech Stack
- **Language:** Python
- **Framework:** Streamlit
- **Logic:** Regular Expressions (`re`)
